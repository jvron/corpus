# Corpus

A performance-focused 3D ECS game engine written in C++.

## Features

- Sparse set ECS
- ECS views
- OpenGL renderer
- Model loading with Assimp
- Texture loading with stb_image
- Material system
- Directional, point, and spot lighting
- Camera system

## Requirements

- C++20
- OpenGL

## Dependencies

- GLFW
- GLAD
- GLM
- Assimp
- stb_image
